🎓 College News & Announcement App

A real-time web application that helps colleges share important announcements instantly with students.
link in live: (https://collagenews-announcement.base44.app)
📌 About the Project

This app allows admins to post college announcements and students to receive updates in real time.
It replaces traditional notice boards with a fast and reliable digital solution.

✨ Features

Admin can add and manage announcements

Students receive updates instantly

Real-time data synchronization

Clean and professional UI

Role-based access (Admin & Student)

🛠 Tech Stack

Platform: Base44.ai

Backend: Firebase

Database: Firestore

Authentication: Firebase Auth

🔄 How It Works

Admin logs in and posts announcements

Data is saved in Firestore

Students see updates instantly without refresh
